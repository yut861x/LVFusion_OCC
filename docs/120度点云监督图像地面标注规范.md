# 120度点云监督图像地面标注规范

> [!IMPORTANT]
> **当前状态：暂不使用。** 现阶段训练与部署仅采用图像和33° LiDAR融合方案，本120° Ouster点云监督流程不纳入当前数据生产、训练或验收，仅保留作为后续方案参考。

委外标注与验收规范 版本 1.1

适用数据包：`20260321-10-45-48`，共1020帧。

## 1 项目目标

本项目使用120度 FOV 的 Ouster 真值点云，为图像分支建立三维地面监督。标注结果只在训练阶段作为真值使用；实际推理仅使用图像和33度 FOV 点云。因此，120度点云是监督来源，不是部署输入。

本任务不要求重新标注已有3D BBox，也不要求对地面进行道路类型细分。标注方应根据三维点云的局部几何关系，将每个可判断点划分为 `ground`、`non_ground` 或 `ignore`，并将结果映射为图像监督。

## 2 核心原则

1. **以三维证据为准。** 图像只用于复核外观、时序和投影，不能替代点云几何证据。
2. **只标记实际观测。** 无回波、被遮挡或无法可靠判断的位置必须保持 `ignore`。
3. **先建立局部地面，再判断高度差。** 禁止只用全局固定Z阈值判断整帧。
4. **障碍物优先于地面。** 已有3D BBox及明确高于地面的实体点不得标为 `ground`。
5. **允许保留不确定性。** `ignore`比例不作为绩效指标，正确表达不确定性优先。
6. **保持三维一致性。** 不得根据二维色块整片填充没有点云证据的区域。

## 3 标签定义

| 标签 | 点级编码 | 定义 | 典型对象 | 后续用途 |
|---|---:|---|---|---|
| `ground` | 0 | 有可靠局部参照，点位于地面表面容差带内 | 机动车道路面、与道路连续的可通行地面 | 地面或free监督 |
| `non_ground` | 1 | 有可靠地面参照，点明显高于地面；或位于有效3D BBox内 | 车辆、行人、护栏、路沿、墙体、树木、路障 | occupied监督 |
| `ignore` | 2 | 缺少可靠参照、被遮挡、过于稀疏、异常或无法判断 | 远处孤立点、异常低点、错位点、无支撑区域 | 不参与监督 |

`non_ground` 不要求细分语义。已有3D BBox内目标保留原语义；其余确认占据但不属于目标类别的点，后续统一作为 `other occupied`。

## 4 地面判定原理

### 4.1 局部地面模型

点云应按方位和距离划分局部区域，在每个区域中从低位、连续且密集的点建立地面候选。候选地面应从近场获得可靠支撑，并沿距离方向连续传播。允许小幅路面起伏和车辆姿态变化，但不得跨越大范围无回波区域直接外推。

当前数据近场地面高度约为 `z=-0.30 m`。该值只用于初始化近场搜索，不代表整帧地面必须等于固定高度。

### 4.2 高度差判定

设点高为 `z_point`，局部地面高为 `z_ground`：

```text
delta_z = z_point - z_ground

|delta_z| ≤ 0.15 m  → ground
delta_z > 0.15 m    → non_ground
delta_z < -0.15 m   → ignore
局部模型不可靠      → ignore
```

明显低于地面的点不能直接判为 `non_ground`，因为可能来自沟槽、反射异常、坐标噪声或错误回波。

### 4.3 连续性要求

- 近场存在稳定地面种子。
- 相邻区域地面高度变化符合道路连续性。
- 地面点在横向有一定分布，不是单条扫描线或少数孤立点。
- 远处范围由连续密集回波支持，不由零散远点延伸。
- 长距离遮挡、点数不足或高度突变后停止传播，后续不确定区域标为 `ignore`。

## 5 non_ground判定原理

只有同时满足“被点云实际观测”和“相对可靠局部地面明显抬高”的点，才能标为 `non_ground`，主要包括：

- 车辆、行人、摩托车、自行车及其他交通参与者。
- 护栏、隔离墩、路灯杆、标志牌、桥墩和墙体。
- 树木、灌木及其他高于地面的绿化物体。
- 高出道路的路沿、施工设施、遗撒物及其他障碍物。
- 已有有效3D BBox内部的点。

不属于已有语义类别的 `non_ground` 仍有占据意义，不得因为无法细分类别而删除。

## 6 3D BBox使用规则

已有3D BBox是真值输入，不属于本次重标范围。

1. 有效白名单BBox内的点优先标为 `non_ground`。
2. BBox内点不参与地面种子估计，防止车底或车身拉偏地面。
3. BBox与地面候选冲突时，以BBox障碍物属性优先。
4. BBox明显漂移、尺寸异常或覆盖大面积真实路面时，不得自行修改，应提交异常记录。
5. BBox外的护栏、路沿、树木等明确障碍点仍需标为 `non_ground`。

## 7 图像监督生成原理

完成逐点分类后，使用相机内参、畸变参数和点云到相机外参，将有效点投影到对应图像。

### 7.1 投影要求

- 图像与点云必须属于同一时间戳或满足约定同步误差。
- 原始畸变图使用畸变参数；去畸变图使用对应的新内参。
- 相机后方、图像边界外和无效点不生成监督。
- 多点落入同一像素时保留距离相机最近的点，避免后景穿透前景。

### 7.2 图像标签原则

- 点云 `ground` 投影为图像 `ground` 监督。
- 点云 `non_ground` 投影为图像 `non_ground` 监督。
- 点云 `ignore` 不产生有效监督。
- 没有点云投影的像素保持 `ignore`。
- 禁止根据纹理、颜色或语义理解，把稀疏投影点之间整片填成 `ground`。

图像主要用于检查投影对齐、辅助识别障碍物归属，并承载图像分支可使用的稀疏监督。三维点云仍是标签依据。

## 8 典型边界案例

| 场景 | 正确处理 | 禁止操作 |
|---|---|---|
| 车辆遮挡路面 | 车辆点non_ground，遮挡后方ignore | 补标车辆下方或后方ground |
| 路沿石 | 高出路面的竖面和顶面non_ground | 为连续性全部标ground |
| 护栏下方 | 实际路面回波ground，护栏回波non_ground | 按二维区域统一赋值 |
| 远处稀疏点 | 有连续支撑才分类，否则ignore | 用孤立点延伸地面范围 |
| 缓坡或车辆俯仰 | 使用局部连续模型判断 | 只使用全局固定Z阈值 |
| BBox与地面冲突 | BBox内保持non_ground，异常上报 | 绕过BBox增加ground面积 |
| 图像边缘 | 使用正确畸变模型，错位上报 | 在错位投影上继续批量标注 |
| 异常低点 | 无法确认时ignore | 直接判为non_ground或ground |

## 9 数据交付要求

### 9.1 点云逐点标签

每帧输出必须与原始 Ouster PCD逐点对应，点数量和顺序不得改变：

```text
0 = ground
1 = non_ground
2 = ignore
```

交付文件应保存源文件标识、点数和校验信息，防止标签与点云错配。

### 9.2 图像稀疏监督

每条有效图像监督至少应包含像素坐标、标签、对应点深度、图像宽高和源点云帧标识。双方可在试标阶段确认最终JSON、NPZ或等价格式。无论使用何种工具，都必须保证标签语义、逐帧对应和最近深度遮挡规则一致。

### 9.3 完整性要求

- 不得重命名、重采样或重排原始点云。
- 每个输入帧应有点云标签和图像监督输出，异常帧另附清单。
- 不得用图像编辑软件制作无法追溯到三维点的稠密标签。
- 交付前验证文件可读取、标签值合法、点数一致。

## 10 质量检查与验收

| 检查项 | 单帧要求 | 批次要求 |
|---|---|---|
| 时序一致性 | 图像和点云目标位置一致 | 异常帧清单完整 |
| BBox保护 | 有效BBox内无ground误标 | 抽检错误率不高于0.5% |
| 地面准确性 | ground贴合路面，不爬上障碍物 | ground精度不低于98% |
| 非地面完整性 | 明显障碍点为non_ground | 明显障碍漏标率不高于2% |
| ignore使用 | 证据不足区域保持ignore | 无大面积无依据ground |
| 投影质量 | 投影与实体位置一致 | 无系统性错位 |
| 文件完整性 | 输出可读且匹配源数据 | 全量对应，异常有说明 |

采用三级质检：标注员自检100%，标注公司质检不少于20%，委托方终验随机抽检不少于10%。发现系统性问题时回退整个受影响批次。

批量生产前应完成不少于30帧试标，覆盖近场车辆、远场稀疏点、护栏路沿、树木遮挡、图像边缘和缓坡场景。

## 11 异常上报

出现以下情况应停止当前帧标注并登记：输入文件缺失；图像与点云不同步；投影系统性偏移；BBox漂移、尺寸异常或坐标系不一致；点云大面积异常或重影；近场地面高与批次基准相差超过0.30 m；输出无法与源点云唯一对应。

异常记录至少包含：帧标识、异常类型、具体位置、问题描述、截图或可视化证据、处理状态。

## 12 提交前检查清单

- [ ] 图像、Ouster点云、BBox和帧标识一致。
- [ ] 已检查近场、中场和远场地面连续性。
- [ ] 车辆、护栏、路沿等障碍物上无明显ground误标。
- [ ] 无点云证据的图像区域未补标ground。
- [ ] 无法判断的点已保留ignore。
- [ ] 图像投影模型与图像畸变状态一致。
- [ ] 输出点数、标签值和源文件对应关系通过检查。
- [ ] 异常情况已登记并提供证据。

## 附录 A 委托方参考工具实现

本附录仅描述委托方现有参考实现，不限制标注公司使用自有工具。标注公司的工具只需满足正文的标签原则、输出语义和质量要求。

### A.1 参考数据目录

| 目录或文件 | 用途 |
|---|---|
| `imgs/<stem>.png` | 图像输入 |
| `pcds_ouster/<stem>.pcd` | 120度监督点云 |
| `pcds/<stem>.pcd` | 33度部署点云，仅对照 |
| `labels/<stem>.txt` | 已有3D BBox真值 |
| `params/cam_intrinsic.json` | 相机内参与8参数畸变 |
| `params/lidar2cam.json` | 点云到相机外参 |

### A.2 参考预分割参数

```json
{
  "ground_z": -0.30,
  "tolerance": 0.15,
  "slope": 0.04,
  "cell": 1.50
}
```

参数仅为当前数据候选初值，不是强制标注规则。标注公司可使用等价或更优方法，但结果必须满足正文验收标准。

### A.3 参考输出与功能

- `ouster_ground_labels/<stem>.npz`：与原始Ouster点序一致的逐点标签。
- `image_ground_labels/<stem>.npz`：经最近深度筛选的图像稀疏监督。
- 参考工具支持候选预分割、投影显示、人工修正、自动保存和回放。

### A.4 OCC转换参考

OCC转换由委托方完成，优先级为：

```text
已有BBox语义 > non_ground转other occupied > ground转free > 未观测区域unknown
```

训练范围外或明确不评价的区域由委托方转换为 `255 ignore`，不要求标注公司生成OCC类别。
